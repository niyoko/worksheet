# Worksheet Interaktif SD

Produk worksheet digital interaktif untuk anak SD. Pembeli memilih kelas anak saat membeli, menerima tautan akses secara manual, lalu anak mengerjakan worksheet di browser. Progres awal disimpan di browser lokal; worksheet juga dapat dicetak atau disimpan sebagai PDF.

## Dokumen produk

- [Product brief dan rencana MVP](docs/product-brief.md)

## Status

Tahap spesifikasi produk. Belum ada aplikasi, integrasi pembayaran, atau materi pembelajaran yang dibuat.

## Asumsi awal

- Target kelas: SD kelas 1–6 Indonesia.
- Pembeli adalah orang tua/wali; anak memakai worksheet tanpa harus membuat akun.
- Akses dibagikan manual setelah pembayaran dikonfirmasi.
- MVP memprioritaskan progres lokal; sinkronisasi server adalah pengembangan berikutnya.
