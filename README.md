# Worksheet Interaktif SD

Produk worksheet digital interaktif untuk anak SD. Launch awal ditujukan khusus untuk kelas 1: 5 worksheet Matematika, 5 Bahasa Indonesia, 5 Bahasa Inggris, dan 5 PPKn (20 total). Pembeli memilih kelas/paket yang tersedia, menerima tautan akses secara manual, lalu anak mengerjakan worksheet di browser. Progres awal disimpan di browser lokal; worksheet juga dapat dicetak atau disimpan sebagai PDF. Kelas lain dan materi tambahan direncanakan untuk tahap berikutnya.

## Dokumen produk

- [Product brief dan rencana MVP](docs/product-brief.md)

## Status

Tahap spesifikasi produk. Belum ada aplikasi, integrasi pembayaran, atau materi pembelajaran yang dibuat.

## Asumsi awal

- Target launch: SD kelas 1 di Indonesia; kelas 2–6 menyusul pada tahap berikutnya.
- Konten launch: 20 worksheet, masing-masing 5 untuk Matematika, Bahasa Indonesia, Bahasa Inggris, dan PPKn.
- Pembeli adalah orang tua/wali; anak memakai worksheet tanpa harus membuat akun.
- Akses dibagikan manual setelah pembayaran dikonfirmasi.
- MVP memprioritaskan progres lokal; sinkronisasi server adalah pengembangan berikutnya.
